# SQLite Support Manual Test Matrix

| 场景       | SQLite 预期                                                          |
| ---------- | -------------------------------------------------------------------- |
| 打开文件   | 选择 `.db` / `.sqlite` 文件后连接成功                                |
| 库表树     | 展示 `main` 与表/视图                                                |
| 表结构     | 展示列类型、可空、主键、默认值                                       |
| 数据浏览   | 分页、排序、WHERE 可用                                               |
| SQL 编辑器 | SELECT、PRAGMA table_info、EXPLAIN QUERY PLAN 可用                   |
| 数据编辑   | 有主键表可增删改，无主键表提示不可编辑                               |
| 索引       | 可查看、创建、删除普通/唯一索引；`sqlite_autoindex_%` 不展示删除入口 |
| 外键       | 可查看，不展示新增/删除入口                                          |
| 触发器     | 可查看定义、创建、删除                                               |
| 概览清空表 | 确认后删除全部数据行并保留表结构，不重置自增序列                      |
| 导入导出   | 概览可选择 `.sql` 文件并导入；不含触发器的基础导出脚本可导入空 SQLite 文件 |
| 触发器导入限制 | 含 `CREATE TRIGGER ... BEGIN ...; END;` 的脚本暂不能完整导入，失败摘要应显示错误 |
| 只读连接   | 概览清空表与导入入口禁用，后端拒绝写操作                             |

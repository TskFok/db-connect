# 复制 INSERT 时选择字段

## 目标

表数据里「复制为 INSERT 语句」改为先弹出居中对话框，由用户勾选要写入语句的字段。去掉「复制为 INSERT 语句（不含主键）」按钮。

## 范围

- 修改 `src/components/table/TableData.tsx` 的复制 INSERT 入口与生成调用。
- 在 `src/utils/sqlUtils.ts` 增加按表列顺序保留勾选列的纯函数。
- 更新 `src/__tests__/copyAsInsert.test.ts`、`src/__tests__/TableDataDeferred.test.tsx`，并补充对话框行为测试。
- 更新 `README.md` 中「可排除主键列」的描述。
- 不改 `generateInsertStatements` 的标识符、字面量和多行格式。
- 不改 JSON 复制、Excel 导出、列显示设置。
- 不持久化本次勾选。

## 交互

勾选至少一行后，工具栏只保留一个「复制为 INSERT 语句」按钮。点击后打开居中 `Modal`，标题为「复制为 INSERT 语句」。

对话框列出 `tableStructure` 的全部列名，包含当前隐藏列。打开时全部勾选。主键列旁显示「主键」标签。列数大于 10 时显示列名搜索，复用 `searchColumns`。提供「全选」和「全不选」。

底部为「取消」和「复制」。「复制」在未勾选任何列时禁用。取消或关闭对话框不写剪贴板。连接、库或表变化时关闭对话框。

确认后按表结构顺序，只用勾选列生成 INSERT，并复制到剪贴板。成功提示为「已复制 INSERT 语句」。未提交的单元格修改仍写入对应列的值。没有勾选行时，按钮本身不出现；若生成结果为空，提示「无法生成 INSERT 语句」。

## 数据

勾选列若包含当前隐藏列且存在可用于定位行的主键，仍走完整行读取，再只把勾选列写入 SQL。否则沿用现有按列补齐大字段的路径。列顺序以表结构为准，不随勾选先后变化。合并未提交修改后，若所选字段仍未加载，则提示错误并中止复制，不生成 SQL、不写入剪贴板；可取消勾选这些字段后重试。

## 测试

- `orderedSelectedColumns`：保留表列顺序、丢掉未勾选列、忽略不在表中的名字、空选择得到空数组。
- 对话框：不含主键按钮不存在；打开后列默认全选且主键有「主键」标签；取消勾选主键后 SQL 不含该列；全部取消后「复制」禁用；取消不写剪贴板；三列时不显示搜索框。
- 既有「没有隐藏列时复制 INSERT 也加载完整大字段」改为在对话框中点「复制」后再断言剪贴板。
